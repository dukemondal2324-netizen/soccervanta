# SoccerVanta Website

Premium SoccerVanta football-intelligence website.

## GitHub Pages

1. Create a **Public** GitHub repository.
2. Upload all files from this folder, keeping `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will publish the site at your Pages address. Publishing can take a few minutes.

## Website details

- Static HTML/CSS/JavaScript; no server is required.
- Telegram CTA: https://t.me/SoccerVantaMatch01
- VIP package information can be edited with the built-in Manage Site panel.
- Manage Site changes are stored in the current browser's local storage, so they are not shared between devices.
